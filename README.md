# PRISM

**Spectral transfer learning for neural networks.**

Hand a fresh model nothing but the *spectral geometry* of a trained one — no weights, no
data — and it trains ~12× faster and stops overfitting. Point the same idea at a trained
model and you can finetune it without catastrophic forgetting. PRISM is the instrument for
extracting and applying that geometry.
